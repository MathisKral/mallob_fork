=== General ===

-J , -jobs (int, default: 0)
	Exit as soon as this number of jobs has been processed (set to 1 if -mono is used)
-SJ , -successful-jobs (int, default: 0)
	Exit as soon as this number of jobs has been processed SUCCESSFULLY (i.e., not cancelled / aborted)
-T , -time-limit (float, default: 0)
	Run entire system for at most this many seconds
-c , -clients (int, default: 1)
	Number of client PEs to initialize (counting backwards from last rank). -1: all PEs are clients
-client-app (string)
	Have clients run specified external program path + "." + i for increasing i (or, if nonexistent, just the path as is)
-client-app-threads (int, default: 1)
	Max. number of applications to run per client
-h , -help (bool, default: 1)
	Print help and exit
-mono (string)
	Mono instance: Solve the provided CNF instance with full power, then exit
-mono-app , -mono-application (string, default: SAT)
	Application assumed for mono mode
-mono-incs , -mono-increments (int, default: 0)
	Whether the "mono" job should be considered incremental
-pre-cleanup (bool, default: 0)
	Clean up shmem/proof/trace/extmem files before starting off
-seed (int, default: 0)
	Random seed
-terminate-abruptly (bool, default: 0)
	Upon termination, avoid waiting for sub-processors to finish
-w , -workers (int, default: -1)
	Number of worker PEs to initialize (beginning from rank #0), -1: all PEs are workers
-warmup (bool, default: 0)
	Do one explicit All-To-All warmup among all nodes in the beginning

	Compress found models into hexadecimal vector in output

-cfci , -clause-filter-clear-interval (float, default: 10)
	Set clear interval of clauses in solver filters (-1: never clear, 0: always clear

-ch , -collect-clause-history (bool, default: 0)
	Employ clause history collection mechanism

-cusv , -compensate-unused-sharing-volume (bool, default: 1)

	Whether LBD should be used as primary quality metric in the inner buckets (bound by "quality" limits)

	Whether LBD should be used as primary quality metric in the outer buckets (bound by "strict" limits)

-mscf , -max-sharing-compensation-factor (float, default: 5)

-nec , -export-chunks (int, default: 10)

-no-import (bool, default: 0)

-qcll , -quality-clause-length-limit (int, default: 60)
	Clauses up to this length are considered "high quality"
-qlbdl , -quality-lbd-limit (int, default: 60)
	Clauses with an LBD score up to this value are considered "high quality"
-randlbd , -randomize-lbd-at-import (int, default: 0)
